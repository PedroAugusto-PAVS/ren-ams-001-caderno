# Caderno de campo REN-AMS-001

Site estático, preparado para publicação no GitHub Pages.

## Publicar no GitHub Pages

1. Adicione `index.html` à raiz do repositório que deseja usar.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**, escolha a branch (normalmente `main`) e a pasta **/(root)**; salve.
4. Abra a URL que o GitHub Pages indicar.

O Pages precisa do `index.html` na raiz da pasta de publicação. A publicação torna o site acessível pelo link. Os registros não são enviados ao GitHub: eles ficam no armazenamento local de cada navegador. Para transferi-los, use **Exportar backup** no aparelho de origem e **Importar backup** no outro aparelho.

## Cópias locais

- `index.html` é a entrada para GitHub Pages.
- `Caderno.html` é uma cópia com o mesmo conteúdo, útil para abrir localmente.

Se alterar o site depois, mantenha os dois arquivos sincronizados ou use `index.html` como cópia principal.
